# Original Literature

The original research papers are NOT included in this GitHub repository.
They can be accessed via their DOIs:

1. Wang et al., J. Chem. Phys. 127, 044506 (2007) — DOI: 10.1063/1.2751191
2. Senthilkumar et al., Phys. Rev. Lett. 96, 086601 (2006) — DOI: 10.1103/PhysRevLett.96.086601
3. Valeev et al., J. Am. Chem. Soc. 128, 9882 (2006) — DOI: 10.1021/ja061827h
4. Coropceanu et al., Chem. Rev. 107, 926 (2007) — DOI: 10.1021/cr050140x

For local setup, create a symlink to the v2 project's original_docs directory:
```bash
ln -s /path/to/naphthalene-transport-v2/original_docs original_docs
```
